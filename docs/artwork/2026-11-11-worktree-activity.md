# Worktree Activity branding

Original artwork for Worktree Activity 0.1.0, created 2026-11-11. The native SVG
icon and generated README banner share deep ink `#0D2730`, petrol teal `#276579`,
pale mint `#B9E7DA`, amber `#F2C078`, and white. A responsible conversation connects
to branches and a retained record. The amber bookmark means an assignment remains
attributable; it is not a running indicator, process lock, or expiration timer.

- Exact tagline: **A thread back to unfinished work.**
- The plugin and marketplace READMEs reuse the same packaged banner. Plugin and
  skill discovery reuse the canonical square SVG; no duplicate runtime assets.
- Banner generated with the built-in Image Generation tool. No external brand,

## Final banner prompt

```text
Use case: ads-marketing. Asset type: final opaque horizontal README banner for an original professional developer plugin, exactly 1536 x 512 pixels, 3:1. Primary request: create a polished branding banner for Worktree Activity, a local tool preserving attribution of unfinished Git work to its responsible conversation across interruptions. Text verbatim: title 'Worktree Activity'; subtitle 'A thread back to unfinished work.'. Render ONLY these words, no other text. Style: restrained sophisticated editorial vector-like illustration, very crisp geometric strokes, deliberate modern white sans-serif typography, spacious hierarchy, subtle tonal depth, absolutely no glossy 3D or photorealism. Composition: left 55% large legible title on two balanced lines if necessary and mint subtitle; right 45% one purposeful visual: a clear speech-bubble root node connected by clean Git-like branching paths to two or three retained document/bookmark records; one small warm amber bookmark visibly anchors the unfinished assignment. Show continuity and retained ownership, not current activity or exclusivity. Palette: deep ink #0D2730 backdrop, petrol teal #276579, pale mint #B9E7DA, restrained warm amber #F2C078, white. Give subtle low-contrast branching geometry in background, never busy. At least 60px edge margins, generous breathing room, impeccable type spacing, readable at GitHub README width. No padlocks, clocks, heartbeats, timers, green running lights, status badges, dashboards, code microtext, mascots, robots, third-party logos, certifications, versions, dates or watermarks. One coherent finished image, not a mockup.
```
