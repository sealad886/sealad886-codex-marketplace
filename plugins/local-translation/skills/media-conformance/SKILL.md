# Media Conformance

Read the [shared expert contract](../.shared/references/expert-contract.md).
Acknowledge this skill, actual actor identity, assigned tracks, old/new assets and
gaps. Establish what changed before deciding which timings or language to reuse.

## When to invoke

Use when a timed track was prepared against another cut, audio version or time
basis, or when a synchronization defect needs diagnosis. You can assess a direct
conformance assignment without an existing translation runtime job.

## Inputs and evidence

- Exact old and distribution video/audio versions, with actual playback access.
- Existing timed track, source/template, event IDs and original review decisions.
- Frame/time basis, delivery profile, edit information and commissioned scope.
- Authorized comparison/timing/export tools and final-track playback capability.
- Relevant translators, revisers, accessibility and content-decision contacts.

## Workflow

1. Verify old/new media and track identities. Inspect synchronization at multiple
   anchors across the programme; compare frame/time bases and selected audio.
   Separate a constant shift from inserted/deleted/reordered scenes or progressive
   drift. A matching runtime or one aligned event is insufficient evidence.
2. Build a changed-interval map with old/new references and stable event links.
   Classify unchanged intervals, moved material, new or removed dialogue, altered
   sound/picture context and changed delivery behavior. Mark unsupported mappings
   as unresolved instead of inventing frame-accurate edit points.
3. Apply only the mapping justified by evidence. A constant offset can repair a
   verified constant shift; it cannot repair structural edits or a wrong time
   basis. Keep previous tracks and decisions intact while producing a traceable
   conformed candidate with documented splits, merges and timing changes.
4. Route changed meaning and new content to the locale translator and independent
   reviser. Route speaker/sound implications to accessibility captioning and
   source ambiguity to the content liaison. Preserve review of unchanged work
   only for its actual unchanged scope; changed assets need renewed evidence.
5. Validate the exported track's structure and project constraints with production
   engineering. Inspect transitions around every changed interval and perform
   the commissioned final-track playback against the distribution cut/audio.
   For a full-playback remit, watch the full track; report partial checks as partial.
6. Reconcile the change list with executed linguistic, accessibility and technical
   checks. Ask the coordinator to propagate shared-source corrections and create
   replacement text jobs where required. Hand the exact conformed output to
   final proofreading, quality evaluation and release preparation.

If a shot is inserted halfway through a programme, shifting every event equally
will leave one side wrong. Map the changed intervals and check both boundaries
before choosing a local shift, new event or renewed language work.

## Outputs and handoff

Use the [expert handoff](../.shared/templates/expert-handoff.md). Return old/new
asset identities, changed-interval/event mapping, conformed file identity,
transformation rationale, outstanding language/accessibility work, validation and
actual playback coverage. Keep supersession links and unresolved mappings visible.

## Completion evidence

Every changed interval is accounted for and supported transformations are applied
to the exact distribution version. Required changed-content reviews and final
playback are evidenced. A missing cut, tool or required review remains a blocker
rather than a claimed completed conform.

## Must not

Do not apply an unexplained global offset, invent timecodes, reuse approval for
changed wording or imply an unchanged duration proves identical content. The
bundled text MCP does not compare recordings or conform timed files. Do not
claim full watchback from samples or distribute a provisional conformed track.
