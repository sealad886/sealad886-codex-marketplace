# Index language and variety inventory

Load this table only when resolving an unfamiliar language/variety, script or
upstream identifier. For ordinary tasks, full language names in the selected
[profile recipe](index-inputs.md#choose-the-commissioned-profile) suffice. Keep
locale conventions separate; an identifier or full name does not prove that the
served model is qualified for a pair. There is no engine language-registry setting
and the existing MCP does not automatically resolve these names for the caller.

This factual inventory is transcribed from the publisher's
[technical report, Appendix C, Tables 32–33, pp. 28–29](https://github.com/bilibili/Index-Translate/blob/912e86c8325d6c7c29a6a0b09c5f53482c6602f6/docs/Index_Translate_Series_Technical_Report.pdf).
It lists 150 language/variety entries and 154 identifiers, including four alias
pairs. Preserve script distinctions, such as Serbian Latin/Cyrillic and Urdu
Latin/Arabic, rather than guessing from a short language code.
