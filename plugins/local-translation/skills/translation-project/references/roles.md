# Responsibilities, interfaces and authority

The supplied *Professional Translation Services* whitepaper describes functions,
not a mandatory staffing count (pp. 4–5). This original mapping retains each
function. Agents assist with the work; they do not become the human client,
qualified linguist, contractual signatory or certification body.

| Whitepaper function | Agent assignment and handoff | Decision boundary |
| --- | --- | --- |
| Client sponsor/localization owner | Intake analyst assembles purpose, locales, budget/resource assumptions and acceptance proposal for the human sponsor | Human confirms scope, permitted disclosure, changes and acceptance authority |
| Client content/creative owner | Content-query liaison consolidates source ambiguities and presents researched options | Actual content owner decides facts, intended meaning and creative departures |
| Account/commercial manager | Scope analyst records requested deliverables, stages, estimates and exclusions for PM | No agent agrees a contract, fee, procurement or external commitment |
| Project manager | Orchestrator dispatches work, manages dependencies, routes questions and assembles evidence | Cannot replace linguistic judgment or invent client decisions |
| Vendor/resource manager | Resource planner assesses available agents/tools, pair/domain evidence, capacity and independence | Agent identity/model name is not a qualification certificate |
| Document/localization engineer | Prepares and verifies supported source units, protects functional tokens, checks coverage and output | Current runtime handles plain text and explicit segments; other formats need a proven external route |
| Translator/audiovisual translator | One locale specialist uses local Index drafting, researches ordinary terms, self-checks and raises queries | Owns target wording proposals; cannot authorize source changes or self-certify independent revision |
| Transcriber/source-language proofer | Conditional source specialist verifies transcript against exact recording and records uncertainty | Needs real recording access and suitable listening/transcription tools; text-only inference cannot verify audio |
| Spotter/template editor | Conditional timed-text specialist establishes/adapts events and context against media | Needs timing/media tools and agreed profile; cannot invent timecodes from text |
| Terminologist/language lead | Defines concepts, provenance and usage conditions; harmonizes locale choices and adjudicates linguistic disputes | Domain expert identifies concept; locale linguist chooses expression; content owner resolves source intent |
| Independent bilingual reviser | Different actor compares source and complete assigned candidate against brief and resources | AI revision is documented as AI revision; it does not establish second-person professional service conformity |
| Subject/client-market reviewer | Domain/market specialist checks technical relationships, organizational usage and audience fit | Cannot establish source fidelity through target-only reading; meaning-changing proposals return to bilingual comparison |
| Caption/SDH specialist | Conditional accessibility specialist checks speaker/sound information against proper audio/picture | Dialogue translation alone is not an accessibility track; requires commissioned scope and media tools |
| DTP specialist/subtitle engineer | Output engineer checks reconstruction, encoding and actual final presentation; conforms media assets when tools exist | Shortening that changes meaning needs linguist agreement; native output/rendering is not supplied here |
| Quality evaluator/quality lead | Applies agreed rubric, adjudicates annotations, reports coverage and corrective actions | Sampling or model scores cannot masquerade as full review or human acceptance |
| Release owner | Evidence coordinator assembles current manifest and unresolved limits for the actual human release owner | Candidate preparation is automated; actual human authorizes identified files for delivery |

Small jobs can combine intake, commercial-scope analysis, resource planning and PM.
Keep translator and independent reviser separate for the same material. Keep
specialist remits explicit even when one agent performs multiple compatible tasks.
The role map is a planning artifact; only actual dispatched work counts as
execution evidence.

The document workflow also names a target-language editor and final proofreader
(pp. 8–9). Commission these as distinct tasks when required: the editor examines
coherence, readability and house style; the proofreader inspects the rendered
final product. Neither replaces bilingual revision, and material wording changes
return for source comparison. For AV, the PM's media-coordination task inventories
the exact cut/audio/track matrix; the subtitle engineer's conformer task compares
and repairs changed intervals against the distribution version. Record these
work products separately even when one suitable agent holds multiple functions.
